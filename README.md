# Prof. Amit Kumar Singh – profile website

A single-page static site. No build step.

## Files
- `index.html` – the whole page (text, styles and chart)
- `photo.png` – portrait
- `Prof_Amit_Kumar_Singh_Profile.pdf` – the 1-page profile offered as a download
- `.nojekyll` – tells GitHub Pages to serve the files as they are

## Put it live with GitHub Pages
1. Create a new **public** repository on GitHub (for example `amit-kumar-singh`).
2. Upload all files in this folder to the repository root (Add file → Upload files → Commit).
3. Open **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
4. After a minute or two the site is live at `https://<username>.github.io/<repository>/`.

To use `https://<username>.github.io/` itself, name the repository `<username>.github.io`.

## Editing
Open `index.html` in any text editor, change the text, and commit. The site updates automatically.
